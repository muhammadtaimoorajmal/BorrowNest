2. **Authenticity Guarantee**: Every photograph represents a real physical object captured with actual photographic equipment. Zero AI-generated synthetic renders or generic clip art are utilized.
3. **Boundary Clarity**: These demonstration photographs illustrate the read-only curated example catalogue. User listings created in the Lending workspace continue to use genuine client-uploaded photos processed locally via the HTML5 Canvas pipeline.
